# Anti-patterns: words and phrases to cut

A longer catalogue of clichés, AI-prose tells, and corporate jargon. Use this when editing marketing copy, blog posts, or anything that needs to sound human rather than machine-extruded.

The pattern is always the same: replace the dead phrase with either a specific fact or a plain-English equivalent. If neither works, delete the sentence — it probably wasn't saying anything.

## AI-prose tells (cut on sight)

These phrases mark text as machine-written. Cut them every time.

| Cut | Replace with |
|---|---|
| delve into | look at, explore, examine |
| navigate (as metaphor) | handle, work through, deal with |
| in the realm of | in, about, when it comes to |
| in the world of | in, about |
| tapestry | (just describe the actual thing) |
| landscape (as metaphor) | (just describe the actual thing) |
| it's important to note | (delete; if it's important, just say it) |
| it's worth noting | (delete) |
| at the end of the day | (delete, or say what you actually mean) |
| in conclusion | (delete; just write the conclusion) |
| in summary | (delete; just summarise) |
| moreover | also, and |
| furthermore | also, and |
| nevertheless | still, but |
| crucial | (usually means "important", but is overused; cut or replace) |
| pivotal | important, key |
| robust | (replace with the actual property: fast, reliable, well-tested) |
| seamless | (replace with the actual experience: "one click", "no setup") |
| holistic | whole, full, complete |

## Corporate jargon (cut in most contexts)

Acceptable inside the company that uses them; usually wrong in writing for outsiders.

| Cut | Replace with |
|---|---|
| leverage (verb) | use |
| utilise / utilize | use |
| facilitate | help, enable, run |
| ideate | think, come up with ideas |
| circle back | come back to, revisit |
| touch base | talk, check in |
| synergy | (delete; usually means nothing) |
| ecosystem (loosely) | (be specific: "our customers", "the developer community") |
| solutions (vague) | (name the actual product or service) |
| stakeholders | (name them: customers, investors, the team) |
| thought leader | (delete; nobody calls themselves this credibly) |
| best-in-class | (show with a fact instead) |
| world-class | (show with a fact instead) |
| next-generation | (show what's new) |
| bandwidth (as metaphor) | time, capacity |
| double-click on | look closer at, dig into |
| north star | goal, priority |
| move the needle | matter, make a difference, work |
| low-hanging fruit | easy wins, obvious first steps |

## Marketing hype (cut without specifics to back them up)

These are fine if you can immediately back them with a fact. Without a fact, cut.

| Phrase | Demand evidence |
|---|---|
| revolutionary | What did it replace? By how much? |
| game-changing | What changed? |
| innovative | What's new about it specifically? |
| cutting-edge | What's the edge? |
| state-of-the-art | According to what benchmark? |
| powerful | Powerful at what? Show the number. |
| amazing / incredible | (delete; let the reader decide) |
| transformative | What did it transform? |
| unlock | (just say what becomes possible) |
| empower | (just say what they can now do) |
| supercharge | (show the speedup) |
| elevate | (show the lift) |

## Hedges that protect the writer

These soften a claim until it means nothing. If the claim is true, state it. If it isn't, cut it.

- "I think it's possible that…"
- "It might be worth considering…"
- "Some would argue that…"
- "It could be said that…"
- "In a sense…"
- "More or less…"
- "Sort of…"
- "Kind of…"
- "Arguably…"

Caveat: hedges are sometimes correct. If the writer is genuinely uncertain, hedging is honest. The problem is hedging out of timidity rather than uncertainty.

## Throat-clearing openers

Cut from the start of any piece, paragraph, or response.

- "I just wanted to…"
- "I hope you're doing well…"
- "First and foremost…"
- "In today's fast-paced world…"
- "In recent years…"
- "Since the dawn of…"
- "It is a truth universally acknowledged…" (only Jane Austen gets this one)
- "Webster's dictionary defines…"
- "Have you ever wondered…"
- "Picture this:" (unless you genuinely paint a picture next)

## Throat-clearing closers

Cut from the end of any piece.

- "I hope this helps!"
- "Hopefully this gives you a sense of…"
- "At the end of the day…"
- "Only time will tell."
- "The future is bright."
- "The possibilities are endless."

## Em-dash overuse

A specific tell of LLM-written prose. One em-dash per paragraph is the upper limit; usually fewer is better. Replace with:

- A full stop and a new sentence (most often the right answer).
- A comma, if the clauses are tightly linked.
- Parentheses, if the inserted clause is genuinely an aside.
- A colon, if the second clause expands or explains the first.

## Adjective stacks

Two adjectives is usually one too many. Three is always too many.

- "fast and efficient" → pick one, or replace both with a number.
- "robust, scalable, and reliable" → name what makes it so, with evidence.
- "warm, welcoming, and inclusive" → describe a moment that shows it.

## Empty intensifiers

These add syllables, not meaning.

- really, very, quite, rather, somewhat
- literally (when used non-literally)
- actually, basically, essentially, fundamentally
- simply, just (most uses)
- absolutely, totally, completely (most uses)

Test: read the sentence without the word. If the meaning is the same, the word was empty.

## Replacements for common weak verbs

| Weak | Stronger |
|---|---|
| made a decision | decided |
| had a discussion | discussed, talked |
| performed an analysis | analysed |
| reached a conclusion | concluded |
| gave consideration to | considered |
| is in agreement with | agrees |
| is reflective of | reflects |
| has the ability to | can |
| is able to | can |

The pattern: nominalised verbs (verbs turned into nouns) drain energy. Restore the verb.
