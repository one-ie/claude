## How It Works (4 steps)
1. Write the agent — 30-line markdown file. `oneie agent new` scaffolds it. Done in 20 minutes.
2. Validate + publish — `oneie agent validate` then `oneie agent publish`. Three-prompt eval gate. Pass → live. Under 60 seconds.
3. The agent learns — Every outcome marks a path. After 50 signals, routing drops from 1,500ms to under 10ms. L5 rewrites the prompt when success rate falls below 50% across 20 conversations.
4. You own the IP — The .md file is in your repo. `oneie agent compile` targets uAgents, MCP, and SKILL.md. Four runtimes, one source.

## Features
1. 30-line definition — name, model, skills, sensitivity, journey, theme, ui. Everything the agent does and looks like. Change one field, redeploy in seconds.
2. Six-minute edit cycle — Pull → edit → validate → publish. Three-prompt eval gate blocks broken agents before any client sees them. Measured.
3. L5 self-improving prompts — success rate < 50% across 20 conversations triggers automatic prompt rewrite. Agent generation increments. No ticket.
4. 20-version history — every publish archives. Roll back any version in one command. Rollback validates before restoring.
5. Four compile targets — web / uAgents Python (Fetch.ai/Agentverse) / MCP tool definition / SKILL.md. Same source file. Four runtimes.
6. No developer required — any team member who can write markdown and run a terminal can author, validate, and publish. npm install, one command.

## FAQs
1. How long to write a first agent? 20-40 minutes with scaffold. 30-line file.
2. Do I need a developer? No. Any team member with markdown + terminal access.
3. What if the agent says something wrong in front of a client? Three-prompt eval gate at deploy blocks it. L5 monitors live success rate.
4. Can the same agent run on multiple client domains? Yes. Publish to multiple workspace slugs. Independent pheromone per workspace.
5. What if the platform changes terms? The .md file is in your repo. oneie agent pull at any time. Open-source substrate.
6. How many agents can a workspace hold? No limit. Credit-based billing on consumption not agent count.
7. What happens to learning when I change the system prompt? Pheromone doesn't reset. Paths built through 50 signals remain. New prompt runs on next signals.
8. How long until the agent is better than day one? Measurably by week six. Significantly by week twelve.
